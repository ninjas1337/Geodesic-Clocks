What you're looking at

Units: G = c = 1, with lengths in units of the body radius. The mass is far larger than any real star relative to its size, so the effects can be seen. All three objects start at the left at the same coordinate time t. That is the time on a clock far from the mass.

Push the fast clock's speed toward c. Its path merges with the light ray, and its elapsed proper time τ goes to zero. A clock can approach the null geodesic but never sit on it.

The slow clock bends mainly because of the time term (the clock-rate gradient you see in the lattice). Light is bent equally by time and by space, which gives the factor 4.

The "warp" is a map, not a literal picture: each point is drawn at radius r(1 + 1.5Φ). A curved 3D space cannot fit inside flat 3D space.

Model

ds² = −(1+2Φ)dt² + (1−2Φ)|dx|² (weak field, γ = 1) a = −∇Φ (1 + v²) + 4 v (v·∇Φ) (geodesic, 1st order in Φ) dτ = dt √[(1+2Φ) − (1−2Φ) v²] α(v)= (2M / b v²)(1 + v²) → 4M/b at v = 1 Δt_Shapiro = 2M ln[(√(L²+b²)+L)/(√(L²+b²)−L)]

The theory column is first order in GM/(c²b). The integrated path also picks up higher-order terms, which the linearized metric only approximates, so the measured α runs a few percent high. The gap grows with the mass slider: that is where the weak-field approximation starts to fail. The frame is finite (|x| ≤ 14), which pulls the measured value slightly the other way. Φ = −M/r outside, uniform-density interior. Integrated with RK4, dt = 0.01.
